# 领域层：定理型研究（数学系 / 理论计算机）

> 适用于：论文的贡献是**命题、定理、界、构造**，而非 benchmark 上的指标。
> 与实验型的根本差别：**证据是证明，不是实验；kill 判据是反例，不是消融。**

## 1. 空位的五种形态

| 类型 | 典型表述 | 怎么判断是空的 |
|---|---|---|
| 界不紧 | "上界是 O(n²)，已知下界 Ω(n)" | 搜索是否有匹配下界；没有就是缺口 |
| 假设过强 | "定理要求分布已知，实际问题里未知" | 看应用段落自认的局限 |
| 结论真空 | "假设在目标场景不可满足" | 构造一个满足假设的实例；构造不出 = 真空 |
| 缺下界 | "只有算法，没有不可能性结果" | 查是否有 Ω 结果；没有就是缺口 |
| 只有存在性 | "证了存在最优解，没给算法" | 看是否给了构造步骤与复杂度 |

## 2. 审稿人三连问（写 idea 时先自答）

1. **定理是否真空成立？** 假设集合是否可满足？**给出一个满足全部假设的具体实例**——给不出就是 vacuously true，等于没证。
2. **界紧不紧？** 上界有没有匹配的下界？没有匹配下界就要说明"下界是 open problem"，不能宣称 tight。
3. **证明是否可核验？** 关键不等式的每一步要能指到引理或已知结果；跨度大的步骤必须单独成为 Lemma。

## 3. 证据惯例

| 主张 | 允许的证据 | 禁止的证据 |
|---|---|---|
| "界是 O(f(n))" | 完整证明 + 常数显式 | "实验上看起来像" |
| "这是紧的" | 匹配下界（同一模型下） | 只做实验对比 |
| "假设弱于 [X]" | 形式化对比表 + 一个 [X] 满足而本假设不满足的实例 | 口头说"更一般" |
| "算法正确" | 正确性证明 + 复杂度证明 | 只给伪代码 |

**数值实验的角色**：只用于**说明**（illustrate）界的行为，不构成证据。审稿人会写"这不能证明任何东西"。

## 4. 伪创新（写出来会被拒）

- **换记号**：把已知结果用新符号重写一遍
- **加强假设求强结论**：假设更强（更特殊）却宣称结论更强（更一般）
- **只给上界不给下界**，然后说"这是最优的"
- **平凡推广**：把标量结论逐坐标推广，无新技巧
- **反例当定理**：只给一个反例，没有刻画反例成立的充要条件

## 5. kill 判据（写进 idea.md §0）

| 编号 | 判据 | 建议阈值 |
|---|---|---|
| K1 | 假设可满足性 | 必须构造出**一个显式实例**并通过全部假设；构造不出 ⇒ 作废 |
| K2 | 结论非平凡 | 存在至少一个满足假设但结论不平凡的实例；否则退化为已知结果 |
| K3 | 反例窗口 | 若有反例，必须给充要参数条件（见 evidence-standards §5） |
| K4 | 与已知结果的关系 | 明确说明是"改进常数 / 放宽假设 / 新下界"中的哪一个 |

## 6. 与实验型的分界

若一篇论文既有定理又有实验（常见于 ML 理论），**以定理为主线**，实验只写在"验证界的可达性"一节，且必须说明"实验不构成证明"。
