# 领域层：实验型研究（应用 CS / AI）

> 适用于：贡献是**方法 + benchmark 指标**，没有定理或定理只是辅助。
> 与定理型的根本差别：**证据是受控实验，kill 判据是对照打平。**

## 1. 空位的五种形态

| 类型 | 典型表述 | 怎么判断是空的 |
|---|---|---|
| baseline 不公平 | "对手没调参 / 算力预算少一个量级" | 看对手是否报了调参预算与搜索空间 |
| 缺消融 | "方法有 4 个组件，只做了整体对比" | 数组件数 vs 消融表行数 |
| 只在易数据上验证 | "10 个 UCI，n<10⁴，ACC>0.95" | 看是否有一个 n≥10⁵ 或公认难集 |
| 指标选择偏差 | "只报 ACC，不报方差" | 看是否给多种子 ±std |
| 复现缺口 | "代码未开源 / 超参不报" | 看附录有没有完整配置 |

## 2. 审稿人三连问

1. **对手预算对等吗？** 你的方法是调过的，对手调过吗？**必须报对手的搜索空间**，否则提升可能是调参带来的。
2. **提升是否超出方差？** 5 个种子 ±std 重叠 = 没提升。必须给多种子、最好多数据集。
3. **有没有 negative control？** 换掉你的核心模块、换成随机基线、换数据集——结果应当变差，否则模块无贡献。

## 3. 证据惯例

| 主张 | 必须给的证据 |
|---|---|
| "优于 SOTA 2 个点" | 多种子均值 ±std + 显著性检验 + 对手调参预算 |
| "模块有效" | 逐组件消融（去一个跑一次）+ 随机同规模对照 |
| "可扩展" | n 从 10³ 到 10⁵ 的耗时曲线（不是单点） |
| "通用" | 至少一个与训练分布不同的数据集 |

## 4. 伪创新

- **换数据集当贡献**（"我们在 XX 上也有效"）
- **只报最好种子**
- **加模块不做消融**
- **用弱 baseline 刷点**（对手用 5 年前的实现）
- **复杂度只报 Big-O 不报秒数**

## 5. kill 判据

| 编号 | 判据 | 建议阈值 |
|---|---|---|
| K1 | 机制存在性 | 去掉核心模块后指标必须下降；不降 ⇒ 机制无贡献 ⇒ 作废 |
| K2 | 对照公平 | 与最强 baseline 打平或更差 ⇒ 降级为工程报告 |
| K3 | 非退化 | 方法不能退化成已知方法（如 k-means 的别名）；给出"换粒/换核"对照 |
| K4 | 显著性 | 5 种子下 Δ 必须 > 合并标准差；否则记为"无显著差异" |

## 6. 与定理型的分界

若你要声称"理论上更好"，必须先有定理；**没有定理时，不要说"更优"，说"在 X 设置下实测更低"**。
