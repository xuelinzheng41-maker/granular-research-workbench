# 粗糙集与粒球研究入口

1. 读 [定义与来源](domain/definitions.md)。先记录目标、文献版本、页码、可用时间、数据与设备。读不了全文就标明；邻近工作没查到不等于新颖。
2. 用 [选题模块](../skills/research-idea/SKILL.md) 比较不同来源的候选，按资源和最小可验证动作筛选。允许没有合格项。
3. 冻结一条可证伪主张，用 [任务模板](templates/study.md) 记录范围。数学：对象、量词、覆盖或划分、精确近似算子；优先找最小反例，再拆引理。有限枚举不等于全称证明。实验：锁定数据版本、切分、口径、基线、随机种子和失败条件；先做配对对照。测试结果出来后不改本轮阈值。
4. 保存原始输入、运行脚本、逐次证据、环境与限制。不具备基线代码或数据时标记缺项；代理实验不能冒充原论文复现。
5. 交另一位研究者重算并决定推进、缩小、暂缓或停止。新主张开新记录，保留旧失败。见 [本地运行说明](README.md)。

只操作用户授权的本地目录。本轮没有自动长时间实验、云端上传或论文写作。
