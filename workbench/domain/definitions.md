# 定义、来源和复现边界

## 数学线：有限清晰覆盖

设 U 有限，覆盖由非空子集组成且并为 U。L_C(X) 是 C 中所有包含于 X 的块的并，U_C(X) 是 C 中所有与 X 相交的块的并。这是本工作台明确选定的清晰覆盖算子，不是模糊粒球粗糙集论文定义的替换品。划分再要求块两两不交。

若每个细块 F 均包含于某粗块 C，则细上近似包含于粗上近似：任何与 X 相交的 F 所在的 C 也与 X 相交。粗下近似包含于细下近似则一般不成立。一个充分条件是每个粗块 C 都等于所有包含于 C 的细块的并：C⊆X 时，这些细块都包含于 X。划分之间的通常细化满足该条件。可按照[工作台指南](../README.md)复算原始反例和有限检查；充分条件乃至反例都是对本定义的推导，不主张文献新颖性。

领域近邻：Yang 等，*Constructing Three-Way Decision With Fuzzy Granular-Ball Rough Sets Based on Uncertainty Invariance*，IEEE TFS 2025，首页 1781。首页确认研究使用模糊粒球、三支决策和不确定性不变性；本试跑没有移植其模糊算子。要扩展到该模型，先逐条摘原论文的定义、定理编号与假设，再比较是否可迁移。

## 计算机线：粒球原型替代的局部验证

从训练样本随机选 64 个原型，用最近原型构造粒群；同一最近类均值分类器分别读取原样本和其粒群原型。固定 3 个划分、距离、原型数、类均值，不调参。这里无自适应分裂、纯度或重采样骨架，不能外推到 GBSK 或其他自适应粒球法。3 个固定划分是机制筛查，不是总体置信推断；不把重复留出视为独立总体样本。

## GBSK：接入历史复现时的边界

参考 [GBSK 原论文](https://doi.org/10.1109/TPAMI.2026.3719825)。原版、只读插桩版和 M-means 等变体应分开登记；逐次记录代码版本、数据集指纹、参数、种子和 ACC/ARI 口径。数据加载存在静默回退风险时，须在评分前验证数据身份。

复跑使用单独的输出目录，不覆盖旧证据；先选一个固定种子的历史记录，比较标签、ACC/ARI、Key Ball 数与失败状态。旧实验的数据、运行记录和本机路径不随工作台分发。仓库内 Digits 示例只是机制筛查。
